## Launch post

I built RepoCity: choose a code folder and it becomes a miniature city.

Files are buildings, folders are neighborhoods, and larger files make taller towers. You can explore, inspect a building, rotate the city, switch between day and night, and export a skyline as a PNG.

It reads only file names and sizes. No uploads, accounts, dependencies or API keys. Download it and open index.html.

I'd love to see what your project's skyline looks like.

Repository: https://github.com/yhajizada/repo-city
